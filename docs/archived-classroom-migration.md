# Archived Classroom Migration Notes

This is an administrative research record for moving useful material from the Class of 2023 and Class of 2024 Google Classrooms into the Class of 2027 project. It is not a source of student-facing deadlines. Every public scholarship still needs a current sponsor check before publication.

## Evergreen guidance carried forward

The current advisory site already included the archive's core guidance on Common App writing, FAFSA/WASFA, college requirements, YVC and Perry Tech steps, BigFuture, and scholarships. The migration added:

- request an official transcript early;
- ask for an application-fee waiver before paying;
- use ASVAB information for military-career exploration without treating a test as an enlistment commitment.

## Added to the Scholarship Finder as planning cards

- Yakima Federal Award for Academic Excellence — 2026 cycle recorded; expected to open around February 2027.
- Northwest Farm Credit Diversity Scholarship — annual March 1 planning deadline; 2027 date still needs sponsor confirmation.

Both cards are explicitly marked as expected information from a prior cycle.

## Kept off the Finder

- Community Safety Network Peer Advocate Scholarship: current program is limited to Jackson Hole High School/Teton County, Wyoming, not Toppenish.
- Washington Award for Vocational Excellence (WAVE): the Washington Student Achievement Council says future scholarships are suspended and there is no 2026 application window.
- Lockheed Martin STEM Scholarship: the sponsor says it is not offering new STEM scholarships.

## Reusable archive structure

The old classes confirm a useful senior-year structure: scholarships, postsecondary applications, financial aid, fee waivers, transcripts, testing, career opportunities, and contact/help. The Class of 2027 site now carries these as student-friendly navigation rather than one-time Classroom posts.
